# Fitness Infinity Hub

Build a responsive web app prototype named “Fitness Infinity” for a capstone project titled:

 

Smart Gym Membership and Trainer Appointment Management System with QR Code Attendance, Online Booking, and Automated Notifications

 

Create a modern, clean, premium fitness-focused interface using a dark navy, white, and energetic green/blue color palette. Use mock data only; this is a clickable prototype, not a production system.

 

Include three user roles with separate dashboards:

 

1. Member

- Sign up and login screens

- Dashboard showing membership status, upcoming trainer appointments, recent QR attendance, and notifications

- Digital QR membership pass for gym entry

- Book a trainer appointment: choose trainer, date, available time slot, and fitness goal

- View, reschedule, or cancel bookings

- Membership plans and renewal page

- Notifications page for booking confirmations, appointment reminders, membership expiry, and gym announcements

- Profile and fitness preferences page

 

2. Trainer

- Dashboard showing today’s appointments, weekly schedule, and assigned members

- Manage availability and time slots

- View booking details and member fitness goals

- Accept, decline, or mark appointments completed

- Send a short message or workout recommendation to members
